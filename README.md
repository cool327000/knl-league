# KNL LEAGUE

Official KNL LEAGUE website template.

## Features
- Standings
- Schedule
- Teams
- League statistics
- Automatic PCT, GB, RD and Magic Number calculations

## How to edit
Open `script.js` and edit the `teams` array to change team records.

## GitHub Pages
Upload all files to a GitHub repository and enable GitHub Pages from **Settings → Pages**.
